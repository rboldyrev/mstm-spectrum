.. _gui_other:

Расчеты Mie и другие вкладки
----------------------------

.. image:: interface_other.png

- Кнопка «плюс» — добавить новый вклад.
- Кнопка «plot» — построить сумму всех вкладов.
- Кнопка «крест» — удалить последний вклад из списка.

.. image:: gui_other_func.png

Каждый вклад имеет свой тип, ряд параметров и индивидуальную кнопку построения графика.

Возможные вклады и их параметры:

1. ConstBkg — добавление постоянного фона
    1.1. Смещение

2. LinearBkg — добавление линейного фона
    2.1. Смещение
    2.2. Наклон

3. LorentzBackground — вклад, имитирующий УФ-поглощение стекла

4. Mie single — экстинкция одной сферы

5. Mie LN — экстинкция ансамбля невзаимодействующих сфер

6. Lorentz peak — лоренцевский пик

7. Gauss peak — гауссовский пик

8. Au film — не реализовано

9. bst-3Au/glass — не реализовано
